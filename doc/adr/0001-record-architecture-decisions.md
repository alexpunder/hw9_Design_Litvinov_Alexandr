# 1. Переобучение модели прогнозирования складских запасов

Date: 2026-05-24

## Status

Accepted

## Context

В ML-системе прогнозирования складских запасов сетевого магазина используется Continuous Training (CT) pipeline на базе Airflow

Одним из SLI системы является метрика `accuracy` модели прогнозирования спроса; для системы установлено SLO `accuracy >= 0.85`

## Decision

Для оценки деградации модели использовались:
- доверительный интервал accuracy
- проверка нормальности распределения
- статистический тест значимости

Обе выборки имеют нормальное распределение (p-value > 0.05), для сравнения использовался t-test. Результат `p-value = 0.00` - обнаружена статистически значимая деградация качества модели. Точность новой выборки нарушает установленный SLO (`0.8014 < 0.85`)

## Consequences

После принятия решения MLOps-система выполняет: запуск retraining DAG в Airflow --> переобучение модели на новых данных --> повторную оценку метрик --> автоматический деплой новой модели при выполнении SLO --> сохранение результатов мониторинга и статистических тестов
